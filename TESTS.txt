   Tests that the standard SauceDemo user can log in successfully and reach the inventory page.

3. InventoryPageLoads
   Tests that the inventory page loads after login and displays all 6 products.

4. ProductCanBeAddedToCart
   Tests that the Sauce Labs Backpack can be added to the cart and the cart badge updates to 1.

5. RemovingLastProductClearsCartBadge

6. BackToProductsReturnsToInventory
   Tests that a user can open the Sauce Labs Backpack product details page, select Back to products, and return to the inventory page.

7. MenuCanBeOpenedAndClosed

8. CartDisplaysCorrectProduct

9. ValidCheckoutInformationIsAccepted

10. ItemSubtotalIsCorrect

11. FinalTotalEqualsSubtotalPlusTax
    Tests that the final checkout total equals the item subtotal plus tax.

12. OrderCanBeCompleted
    Tests that a standard user can complete the checkout process and reach the order confirmation page.

13. UserCanLogout
    Tests that a logged-in user can open the navigation menu, log out, and return to the login page.
